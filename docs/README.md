# aiofiles docs

The root [README](../README.md) covers install, volumes and security. These four
go deeper.

- [configuration.md](configuration.md) — every environment variable, its default,
  and the ones with rules you cannot guess from the name.
- [api.md](api.md) — the HTTP API: routes, bodies, status codes, the SSE event
  stream, and curl examples that actually run.
- [troubleshooting.md](troubleshooting.md) — the failures you are most likely to
  hit, each as symptom, cause and fix.
